# Job Application Tracker

A simple single-page app to track job applications: log each application,
move it through statuses (Applied → Screening → Interview → Offer / Rejected),
filter, search, and see counts at a glance.

Built with [Next.js](https://nextjs.org). Data is stored in the browser's
`localStorage` — no backend, no account, nothing leaves your device.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push to GitHub and import the repository in Vercel — no extra configuration
needed.
